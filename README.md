# SigmaOS-gpu

> **SigmaOS GPU & Acceleration Subsystem** — DRM/KMS, Mesa, Vulkan driver integration, hardware acceleration pipelines, and Wayland compositor rendering support.

Part of the [SigmaOS](https://github.com/AaryanSinghChauhan09/SigmaOS) ecosystem.

## Quickstart

```bash
cargo build --release
cargo test
```
